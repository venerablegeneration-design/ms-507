MBS MAGNIFICENT SHOW 507 - WEBSITE
=====================================

CARA MEMBUKA:
1. Extract ZIP ini.
2. Buka folder MBS-WEBSITE.
3. Klik dua kali index.html.
4. Website akan terbuka di browser.

KUSTOMISASI:
- Ganti assets/logo.svg dengan logo MBS asli (ubah referensi di index.html bila nama file berbeda).
- Ganti assets/hero.svg dan file gallery dengan foto sendiri.
- Tanggal countdown diatur di script.js pada variabel eventDate.
- Link Instagram/TikTok/YouTube dapat diubah di index.html.

Catatan:
File SVG sementara disediakan agar website langsung tampil tanpa aset eksternal.
